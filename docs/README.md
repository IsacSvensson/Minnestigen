## Evidensnivåer

Används genomgående, i dokumenten och i kodkommentarer.

| Nivå | Betyder |
|---|---|
| **N1** | Vetenskapligt välbelagt: flera metaanalyser eller replikerade experiment |
| **N2** | Lovande men osäkert: få eller små studier, främst vuxna, eller utan kontrollgrupp |
| **N3** | Praktisk erfarenhet från minnesexperter, inte prövad i forskning |
| **N4** | Hypotes eller eget produktförslag – ska kalibreras i piloten |

## Målbild i en mening

Efter några månader ska barnet självmant kunna tänka: *"Det här behöver jag komma
ihåg. Jag gör en bild av det, testar mig själv senare och kollar om jag fortfarande
kan det."* Det är förmågan att **välja, använda och utvärdera en strategi** som appen
ska utveckla och mäta.
