# Produktregler

Icke förhandlingsbara krav, samlade från hela underlaget. Varje ändring i appen ska
hålla dem. Använd listan vid kodgranskning.

## Pedagogik
- [ ] **Rätt svar visas alltid direkt efter varje försök** (yngre barn behöver det, N1).
- [ ] Allt som lärs in **kommer tillbaka som hämtning** enligt schemat – inget lärs in
      bara en gång.
- [ ] Repetitionsintervall är **jämna eller lätt växande**; **tätare för bildbaserat**.
- [ ] Barnet **försöker minnas innan det tittar**; ledtrådar ges stegvis (första
      bokstaven → platsen → bilden → svaret).
- [ ] **Förstå först:** minnestekniker bara för godtyckligt stoff; förstå-kontroll innan
      nytt stoff kodas.
- [ ] **Färdiga bilder före egna**, berättelse före minnespalats.
- [ ] Stödet tonas ut efter **fördröjt resultat**, inte ålder eller antal pass.
- [ ] Vid utnyttjandeunderskott: **fler exempel och förklaring, inte nästa nivå**.
- [ ] Varje pass har en **reflektionsfråga om strategin**, inte om poäng.

## Motivation och belöning
- [ ] Huvudmåttet barnet ser är **långtidsminne** ("Du kom ihåg 8 av 10 från förra veckan").
- [ ] Belöna försöket att plocka fram, motiverade val, ärliga gissningar, vardagsuppdrag.
- [ ] Världen låses upp av **deltagande**, aldrig av prestation. Barnet kan aldrig fastna
      för att det minns dåligt.
- [ ] **Aldrig:** streaks, tidspress, topplistor, köp i appen, lootboxar, skam vid paus.
- [ ] Poäng, snabbhet och dagar i rad **räknas inte som lärande**.

## Påståenden
- [ ] Lova aldrig bättre betyg, koncentration, intelligens eller effekt vid ADHD.
- [ ] Fokuseringsrummet motiveras aldrig med bättre minne; alltid valfritt.
- [ ] Ingen arbetsminnesträning eller "hjärngympa".

## Integritet
- [ ] Vårdnadshavares samtycke före användning.
- [ ] Hemmabilder lagras **endast på enheten**.
- [ ] Inga sociala funktioner, ingen reklam, ingen profilering.
- [ ] Inget av barnets data lämnar enheten utan vårdnadshavares uttryckliga val
      (och då minimerat och pseudonymiserat).

## Rättigheter och grafik
- [ ] **All grafik är egenritad** för projektet (se [design/grafik.md](design/grafik.md)).
- [ ] Inga GMS-namn, -texter eller -kodtabeller; egna kodtabeller och övningar.

## Tillgänglighet
- [ ] Instruktioner kan **läsas upp**; svar kan ges med tal eller bild, inte bara text.
- [ ] Stora tryckytor (≥ 60 px), hög kontrast, respekterar "reducera rörelse".
- [ ] Korta pass (5–10 min) med möjlighet till paus.
